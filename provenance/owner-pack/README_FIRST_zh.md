# Echoes of the Valley · B5 环境美术补充包

> 2026-10-29 · 美术候选素材包，**不是** Unity 集成完成、实机画面或 Gate B5 通过的证据。

## 为什么制作这包

Phase 5.2-B4 的女主、炼金工坊和垂柳已形成较好的 2.5D 方向，但 B2 遗留草地、田地和低多边形树木仍与其不协调；旧泉水的画面尤其薄弱。本包集中提供 6 张新绘制素材供 Claude Code 在 B5 做真实场景集成。**不重新制作 B4 的女主、房屋或垂柳。**

## 已验证和未验证

- 六张 PNG 可读；四张道具图有透明 Alpha，两个地面图是 RGB。
- 原图尺寸、文件 SHA-256 见 `SHA256SUMS.txt`。
- **尚未**导入 Unity、运行 Windows Build、验证碰撞、任务、存档、帧率、场景透视和实际遮挡。
- **不能直接宣称**草地/土壤已经无缝平铺；生成时要求了无缝，但必须在实际 4×4 贴片和 TerrainLayer 中检验接缝，并修复。
- 透明道具图轮廓可能有鲜红/浅色杂边；在 Unity 导入前应清除色边、空白像素和 Alpha 污染，并对照底色测试。
- 两张泉水图共享设计，但并非逐像素配准的同一对象；阶段过渡需要对齐锚点、裁切、必要时局部重绘，避免整体跳跃。
- **重要：S0 图仍画有两道流水与池水，只做到冷暗，不等于“干涸”。** 如果剧情的 Silence/S0 是枯竭状态，Claude Code 必须对水流层做进一步美术修整，否则 Stage 对比不合格。
- 庭院/泉水是高细节静态插画；实际游戏中仍须核对视角、角色比例、落地阴影、人物前后层级。不能把单张漂亮素材当作实机场景质量。

## 技术方向

1. 维持固定 camera yaw 45°、默认 pitch **48°**，沿用 B4 的 2.5D 分层表现和原有真实 3D 地形/碰撞交互，不重做关卡。
2. 泉水最重要：将 S0 和 S3 绑定到**真实的游戏阶段**，S1/S2 要有渐进变化（例如水色/花卉/灯光/特效），不要直接把 S3 作为所有状态，也不要脚本强制达成阶段。保留真实可交互泉水区域和地面通行能力。
3. 草地/土壤按实际场景比例、颜色校正、边缘混合使用；不能简单把画布贴到一整块地上。支持 TerrainLayer 混合、法线/粗糙度和轻度色彩变化。
4. 苗圃图只做**静态展示**；现有种植、采集、浇水、任务触发点和 NavMesh 必须继续工作。
5. 树要建立遮挡策略：角色进入树冠范围时让树冠局部淡出/裁切，不得让人物被完全盖住。根部有可信的地面阴影。
6. 视觉统一以 B4 现有女主、房屋和垂柳为基准；不能让新素材的金黄/饱和度盖过人物。
