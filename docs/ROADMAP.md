## 选择后续任务的规则

1. 先选能填补真实工程缺口、能在本机零付费验证的任务。
2. 每个实验先写资源边界、版本、命令、预期、实测、失败与清理。
3. 先本地隔离验证，再决定是否接入云或外部服务；不得声称未运行的外部验证已通过。
4. 每个阶段结束后更新本文件和 WORKLOG，再开始下一阶段。
