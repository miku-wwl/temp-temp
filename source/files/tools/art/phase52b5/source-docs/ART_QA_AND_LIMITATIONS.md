# B5 美术包初步 QA / 局限

## 本地基本检查

六张 PNG 均已保存、可解码。`spring_S0_dormant`、`spring_S3_restored`、`farm_raised_beds`、`broadleaf_tree` 为 RGBA，Alpha 最小值 0、最大值 255；草地/土壤贴图为 RGB。

## 视觉复核备注

1. **S3 泉水**：精细度、配色、材质明显强于 B4 截图中泉水，水池、石柱、苔藓层次更好。但这是孤立的绘制道具：其自然透视、大小、脚底遮挡、接地、静态水流必须经 Unity Player 截图/视频验证。
2. **苗圃**：高质量静态插画，包含已经生长的蔬菜与花朵；如果游戏实际作物未成长或已收割，必须分离作物视觉，避免状态错位。
3. **草地**：纹理细节丰富，但高饱和黄绿色、重复贴图缝和远景噪声风险较高；先对照 B4 主角/工坊色温调色，再检查真实 1080p。
4. **树木**：只有一棵候选阔叶树，不能凭此宣布所有旧 B2 树已消失；还需要依地标定位和遮挡风险逐处更换或降级处理。
5. **透明边缘**：部分绘制道具的 Alpha 外缘可以看到零星鲜红色污染，必须在生产化过程中清理后复查黑/白/绿/棋盘底色；尤其不能直接把原 PNG 导入游戏而不检查。
6. **S0/S3 配准和语义**：两图并非保证逐像素匹配，不能直接淡入淡出整张图而忽略地形与石柱跳跃。更重要的是现有 S0 图依然有明显的水流和盛水池，实质是调暗版，并非真正干涸的泉水；若剧情要求泉水枯竭，则**S0 美术仍为 PARTIAL**，必须进一步重绘或遮蔽水流。
7. **地表平铺实测**：原图相对边缘 RGB 绝对误差（MAE，0–255）草地左/右 `16.35`、上/下 `14.67`；土壤左/右 `13.15`、上/下 `11.51`。这项粗略测量不直接代表视觉上能否发现接缝，但支持 **不能直接声称 seamless**，必须实机 4×4 检验与修补。
