# Phase 5.2-B4 Art QA Checklist / 美术导入检查表

## 图片源稿完整性

- [ ] ZIP 与 `SHA256SUMS.txt` 核验通过；22 张新 PNG + 3 张用户既有参考图齐全。
- [ ] 每张 PNG 在 Unity 中实际可加载；RGBA alpha 与材质色彩空间（sRGB / Linear）设置符合用途。
- [ ] 所有源稿已建立对应 Unity `.meta` 并纳入版本管理；禁止重新生成时覆盖原图。

## 主角绘制与动作

- [ ] N/S/W/E idle 为自然垂臂，姿态与 B3 脸型/服装一致。
- [ ] 四张 run key-pose sheet 可拆分为**真实分离**的有效动作姿态，逐帧没有断肢、重影、衣物/饰品明显瞬变。
- [ ] 所有方向的人物足底 pivot、人物高度、站立与行走大小一致，避免转向时瞬间变高/变矮。
- [ ] 全部角色 alpha 在白色、黑色、草绿色、土黄色背景下没有明显灰褐色雾晕、红边、黑边或背景矩形。
- [ ] 跑步期间脚步、摆臂和马尾/衣摆有**少量自然运动**，站住后自然回 idle；不强制高复杂度 3D 骨骼或过量动效，也不是一个静态立绘整体滑行。
- [ ] 四向和斜向动态、面朝镜头/背对/侧身、原始人物根运动与碰撞关系均有真实 player 画面证据。

## 静态环境材质与 2.5D 层次

- [ ] 4 张墙/瓦/木/石原图在真实 3D 网格的 UV 上不会有无法接受的接缝；必要时修复平铺边缘或退回旧材质。
- [ ] 已实测 `environment/isometric-static-props/` 的工坊/垂柳/遗迹候选插画：固定相机下角度合适、视觉占地正确、玩家遮挡可信。允许采用精细的静态 2.5D 分层插画，无须动态 3D 植物。
- [ ] 如果混合 3D 和绘制的植被/建筑，接触点、地面投影、方向与深度排序自然，不出现“贴上去的纸片矩形”。
- [ ] 草丛花卉与相机的透明排序稳定；没有彩色/黑色大光晕或严重过度绘制。
- [ ] 工坊房屋在**实机可见外观**中有屋檐、石基、窗框和梁柱等视觉体积；可以是高质量静态 2.5D 画稿或现有网格+精细材质。所有 E 交互仍正常。
- [ ] 垂柳、工坊、道路三处的前后变化在真实玩家 1080p 截图中明显且美术风格协调。

## 镜头、小地图与 UI

- [ ] 在 42°/48°/54° 试点中选定更高的斜俯视角，记载采样截图与最终角度。
- [ ] UI 地图来自真实世界地形/bounds，不是静态冒充；玩家位置和朝向变化会同步。
- [ ] 顶部 HUD 与地图不重叠；720p/1080p、暂停/对话/背包无遮挡。
- [ ] 小地图框的中心真的透明，外圈无明显红/白/暗色杂边。
- [ ] `art-direction/b4_isometric_style_target.png` 仅作为原创视觉目标展示，不作为假的实机截图或整张背景图。
- [ ] 不强制让草花、树叶、房屋发生动画；主要完成静态美术质量、层次和人物轻动效。

## 可发布性与责任边界

- [ ] 游戏故事/收集/炼金/存档/三个 Resonance 和结局全部仍能进行。
- [ ] Unity 全量测试与真实 Windows player build、真实移动录像和性能测试完成。
- [ ] 玩家亲自试玩与人工美术审批尚未发生时，状态仍为 `PENDING`。
- [ ] AI 生成来源已如实记录；所有 3D 资产如果来自外部，单独列许可证；不可称此图片包包含 FBX/Blend。

仅成功导入 PNG、测试绿灯或编辑器截图均**不足以宣布 Gate B PASS**。
