### 最新美术要求（优先级最高）

- 参考主人新提供的两张 2.5D 斜俯视 RPG 实机截图：**高角度固定相机、茂密静态植被、细节丰富的石路与建筑、高质量材质层次**。
- 再结合温暖、青春、精致的日式炼金冒险气质：奶白石墙、暖木、红瓦、丰富草绿、少量金铜与蓝色炼金光效。**只提取通用美术原则，不复制已有游戏受保护的角色、纹理、地图或 UI。**
- **人物立绘保留**；只要求自然站姿、轻量呼吸/衣摆/发丝动作、可信的有限步态，避免 A-pose 和滑动纸片人，不追求重型 3D 骨骼动画。
- **树木、花草、房屋可以全部保持静态。** 本轮改的是静态美术质量、细节密度、遮挡、配色与画面统一性，不是强迫所有场景物体动起来，也不强制所有物体重建为昂贵的 3D 网格。

## 2. 质量与适用范围：请先读

1. 当前文件已是可打开的 PNG，透明角色/植物图带 RGBA 通道；但 **RGBA 不等于天然无瑕抠图**。部分背景为渐变透明光晕或彩色半透明像素，应先做 alpha 清理、颜色外扩和黑白背景检视，再进入 Unity。尤其小地图框边缘可能有红色杂边，需验收后使用。
2. `hero_run_*.png` 是“四个动作姿态绘在一张大画幅”的 **source sheet**，并非精确等分、可直接导入的最终 Sprite Atlas。四方向尺寸略有不同。需要人工/脚本识别姿态区域，逐张去底、统一足底中心/视高/比例和身体造型。不可将整张横图当一帧。
3. 四方向画稿由生成模型独立绘出，发型、包带、装饰与服装细节**可能有细微漂移**。游戏内需抽样 10 次完整转身，避免人设变化。如果无法消除关键差异，明确标记 `PARTIAL`，不要自评 `PASS`。
4. 本轮允许 **静态 2.5D 场景 + 少量人物动画**。可以保留现有 3D 地面与碰撞，使用固定斜俯视分层插画提升树木、工坊、遗迹外观；也可以用插画指导 3D 材质与网格改进。哪种看起来更好且可玩性稳定，就采用哪种。**不必让环境动起来。** 本包没有 `.fbx`、`.blend`、骨骼或专业 3D mesh，不可对外声称包含这些模型。
5. 材质虽按“可平铺”提示生成，但尚未逐边做像素级周期性接缝检查。若有接缝，需修图/重新投射后再启用 Repeat，**不得声称已无缝或已做好 PBR**。
6. 这些素材是原创 AI 生成插画/参考源稿，灵感取自温暖、精致的日式乡村幻想 RPG 美学；**不得复刻《莱莎的炼金工房》任何角色、地图、标识、服饰或受保护素材**。最终发布所需 AI disclosure / rights 文案仍需用户审核。

## 3. 推荐接入顺序

1. 分离一份安全的 B4 pilot 场景与构建；原 RC1/RC2、B2、B3 可回退。
2. 把相机从现有 pitch≈30° 提升至约 45°～55° 范围，1080p 真实验证可读性、遮挡和交互。
3. 使用 `art-direction/b4_isometric_style_target.png` 为风格指引，先在广场、炼金工坊、垂柳与泉水周边做**静态环境**前后对比；不必强制 3D 建模，不需要场景动画。
4. 制作真实小地图：实际世界 X/Z → UI 坐标，显示玩家朝向、任务目标、重点设施。`ui/minimap_frame.png` 只是外框。
5. 同时把主角自然待机与有限有效走姿纳入 B3 的 `SpriteSheet25D` / `CharacterVisual2D5D`；遵守动画测试与真实性门槛。**不要启动 Phase C/D 地图扩建。**
6. 输出真实 Windows-player 截图、至少 30 秒持续移动录像、测试、性能、审阅报告，再请求用户评定 Gate B。
